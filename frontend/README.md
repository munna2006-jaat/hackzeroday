# HackZeroDay Frontend

Static first-page prototype for HackZeroDay Labs.

## Structure

- `index.html` - home page layout
- `styles/main.css` - responsive UI, animations, theme
- `scripts/main.js` - cursor glow and ticker behavior
- `assets/` - add logos, screenshots, lab thumbnails, student photos, and CTF graphics here
